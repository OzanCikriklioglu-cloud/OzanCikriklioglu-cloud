**CS Student | Backend, Cloud & Security-aware Systems**

I'm a Computer Science student focused on backend development and building reliable software systems.

I work primarily with Spring Boot and focus on designing backend services with clean structure, proper data handling, and reliability in mind. Alongside backend development, I explore cloud deployment and applied machine learning through academic projects.

My projects often include asynchronous processing, event-driven patterns, REST APIs, databases, and practical ML workflows such as classification, forecasting, preprocessing, and model evaluation.

While I have a strong interest in security, I treat it as a natural part of backend development rather than a separate layer.
