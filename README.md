CS Student | Backend & Cloud (Security-aware)

I’m a Computer Science student focused on backend development and building reliable systems.

I work primarily with Spring Boot and focus on designing backend services with clean structure, proper data handling, and reliability in mind. Alongside backend development, I’ve been exploring how to run these systems in cloud environments.

My projects often include asynchronous processing and event-driven patterns, and I try to build systems that are not only functional but also stable and observable.

While I have a strong interest in security, I treat it as a natural part of backend development rather than a separate layer.
